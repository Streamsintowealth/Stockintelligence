# Streams Into Wealth — Stock Intelligence Hub v2.0

A responsive five-page website for GitHub Pages.

## Upload instructions
1. Extract the ZIP on your computer.
2. Create a NEW public GitHub repository, e.g. `stock-intelligence-hub`.
3. On the repository main page, choose **Add file → Upload files**.
4. Upload the **contents** of this folder, not the ZIP or enclosing folder. You should see `index.html`, `research.html`, `trading.html`, `markets.html`, `hub.html`, and `assets/` at the repository root.
5. Commit changes.
6. Go to **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
7. After deployment, open `https://YOUR-USERNAME.github.io/stock-intelligence-hub/`.

## Features
- Five pages: Home, Research, Trading, Markets, My Hub.
- Subpages (tabbed panels) within Research, Trading, Markets and My Hub.
- Responsive DM Sans / Nunito Sans typography, green/gold branding, mobile menu.
- Search among 10 starter company/ETF profiles.
- Company sector, industry, business segments, moat and risks.
- Chart/table switching, tooltips, investor relations links.
- Local watchlist and research journal.

## Important data limitations
The site is an **offline-friendly UI starter**, not a live data service. Charts are explicitly illustrative; financials, executive tenures, institutional flow and analyst targets are intentionally not invented. News and filings open official/external sources. No API keys or paid feeds are needed to run the starter.
